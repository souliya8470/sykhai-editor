# N8N → โหลดคลิป TikTok อ้างอิงเข้าโปรแกรมตัดต่ออัตโนมัติ

```
N8N (workflow นี้)  ──POST /fetch──▶  เซิร์ฟเวอร์ตัดต่อ (server.js) ── yt-dlp ──▶ D:\SykhaiEditor\inbox\<video_id>.mp4
                                                                                   │
โปรแกรมตัดต่อ (v1.30+)  ◀── เปิดโปรแกรม = ดึงเข้าลิสต์มีเดียเอง / ปุ่ม 📥 ในแท็บ AI → 🔬 ──┘
                                              (ดึงแล้วไฟล์ย้ายไป inbox\done, ไม่โหลดซ้ำ)
```

## ติดตั้ง (ครั้งเดียว)
1. อัปเดตไฟล์ `server.js` ในโฟลเดอร์ sykhai-server (เซิร์ฟเวอร์รีสตาร์ทเองภายใน ~5 วินาที) — ครั้งแรกที่มีคำสั่งโหลด เซิร์ฟเวอร์จะดาวน์โหลด `yt-dlp.exe` ลง `D:\SykhaiEditor\tools` เอง
2. N8N → Workflows → ⋯ → **Import from file** → เลือก `sykhai-tiktok-inbox.workflow.json`
3. เปิดโหนด **ตั้งค่า** แก้ 2 ช่อง:
   - `server` — ถ้า N8N อยู่เครื่องเดียวกับเซิร์ฟเวอร์ตัดต่อใช้ `http://127.0.0.1:8787` ถ้าคนละเครื่องใช้ `http://192.168.0.25:8787`
   - `token` — รหัสผ่านเซิร์ฟเวอร์ตัดต่อ (อยู่ในไฟล์ `token.txt` ข้าง `start.bat`)
4. กด **Execute workflow** — โหนด "เลือกคลิปที่จะโหลด" ตั้งไว้สูงสุด 50 คลิปยอดวิวสูงสุดของภาษาไทย (เฉพาะยอดวิว ≥ 10,000 ตอนนี้มีราว 20 คลิป) — ภาษาลาวปิดไว้เพราะในลิสต์ยังไม่มีตัวเลขยอดวิว จึงเลือกคลิปที่ดีไม่ได้ (แก้ `PER_LANG` / `MIN_PLAYS` ได้)
5. เปิดโปรแกรมตัดต่อ → คลิปเข้าลิสต์ "สื่อ" เอง → แท็บ AI → 🔬 วิเคราะห์ → เริ่มวิเคราะห์ (ชื่อไฟล์ = video_id จึงจับคู่กับรายการอ้างอิงให้อัตโนมัติ)

ตัวกำหนดเวลาทุกวันจันทร์ตี 2 ถูกปิดไว้ — เปิดเมื่อต้องการให้เติมคลิปใหม่เรื่อยๆ (คลิปที่เคยโหลดแล้วจะถูกข้ามเอง)

## ตรวจสถานะ
เปิดในเบราว์เซอร์: `http://192.168.0.25:8787/fetch?t=<token>` → เห็นเวอร์ชัน yt-dlp, คลิปที่รอใน inbox และ log 20 บรรทัดล่าสุด (บอกสาเหตุถ้าโหลดไม่ได้)

## ถ้าโหลดไม่ได้
- **"yt-dlp.exe รันไม่ได้ / EPERM"** — Windows บล็อกไฟล์: คลิกขวา `D:\SykhaiEditor\tools\yt-dlp.exe` → Properties → Unblock หรือเพิ่มโฟลเดอร์ `tools` ใน Windows Security → Exclusions
- **HTTP 403 / "Unable to extract"** — TikTok เปลี่ยนระบบ: ให้เซิร์ฟเวอร์อัปเดต yt-dlp (ลบ `tools\yt-dlp.exe` แล้วสั่งใหม่) ; ถ้ายังไม่ได้ ใช้ทางสำรอง: โหลดมือแล้วลากไฟล์ที่ตั้งชื่อ `<video_id>.mp4` ลงโฟลเดอร์ `D:\SykhaiEditor\inbox`
- โหลดมากเกินไปในเวลาสั้นๆ TikTok อาจจำกัด — workflow พัก 20–40 วินาทีระหว่างคลิปไว้แล้ว

ใช้เพื่อศึกษาเทคนิคตัดต่อภายในร้านเท่านั้น (เก็บเฉพาะตัวเลขที่วัดได้ ไม่เผยแพร่คลิปต้นฉบับ)
