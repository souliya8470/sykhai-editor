# เซิร์ฟเวอร์เก็บไฟล์ของ Sykhai Editor

เก็บโปรเจกต์ + วิดีโอต้นฉบับ + วิดีโอที่ตัดเสร็จ ไว้ในดิสก์ของคอมเซิร์ฟเวอร์ที่ร้าน (ค่าเริ่มต้น `D:\SykhaiEditor`)

## ติดตั้ง (ทำครั้งเดียว บนคอมเซิร์ฟเวอร์)
1. ติดตั้ง Node.js เวอร์ชัน LTS จาก https://nodejs.org (กด Next ไปเรื่อยๆ)
2. คัดลอกโฟลเดอร์ `server` ไปไว้ที่เครื่อง เช่น `D:\sykhai-server`
3. เปิด `start.bat` ด้วย Notepad ไม่ต้องแก้ไฟล์ — ครั้งแรกที่ดับเบิลคลิก `start.bat` จะถามให้ตั้งรหัสผ่าน (พิมพ์เองในหน้าต่างดำ เก็บในไฟล์ token.txt ข้างๆ)
4. ดับเบิลคลิก `start.bat` — ถ้าขึ้นว่า “พร้อมแล้ว” คือใช้งานได้
5. `start.bat` ตั้งให้เปิดอัตโนมัติทุกครั้งที่ล็อกอิน Windows ให้เอง (Task Scheduler ชื่อ SykhaiEditorServer)

## เชื่อมต่อจาก Mac (แนะนำ: Tailscale ได้ https + ไปทางวงแลนในร้านโดยตรง)
1. ติดตั้ง Tailscale ทั้งบนคอมเซิร์ฟเวอร์และ Mac (ล็อกอินบัญชีเดียวกัน)
2. ใน https://login.tailscale.com/admin/dns เปิด “HTTPS Certificates”
3. บนคอมเซิร์ฟเวอร์ เปิด Command Prompt พิมพ์: `tailscale serve --bg --https=8787 http://localhost:8787`
4. คำสั่งจะแสดงที่อยู่ เช่น `https://ชื่อเครื่อง.xxxx.ts.net:8787` — เอาไปใส่ในโปรแกรมตัดต่อที่ ⚙ ตั้งค่า → เซิร์ฟเวอร์เก็บไฟล์ พร้อมรหัสผ่าน แล้วกด “ทดสอบเชื่อมต่อ”

(ถ้าเปิดโปรแกรมตัดต่อด้วย http:// ธรรมดาและทดสอบในวงแลน จะใช้ `http://IPของคอมเซิร์ฟเวอร์:8787` ก็ได้ แต่ถ้าเปิดเป็น https:// เบราว์เซอร์จะบล็อก ต้องใช้ที่อยู่ https ของ Tailscale)

## โฟลเดอร์ที่ได้
- `media/` ไฟล์ต้นฉบับ (ชื่อเป็นรหัส) · `projects/` โปรเจกต์ · `out/` วิดีโอที่ตัดเสร็จ (ชื่อจริง เปิดดูได้เลย)
- ควรสำรองโฟลเดอร์ `D:\SykhaiEditor` ไปดิสก์อีกลูก/NAS เป็นระยะ

## ความปลอดภัย
ทุกคำขอต้องมีรหัสผ่าน (`x-token`) ไม่เปิดออกอินเทอร์เน็ตสาธารณะ ถ้าใช้ผ่าน Tailscale มีเฉพาะเครื่องในบัญชีคุณที่เข้าถึงได้
